## 🔧 プレースホルダーの書き換えが必要なファイル

### `ショトカボタン/portal-shortcut.js`

ポータルに配置するアプリ一覧（`appList`）がプレースホルダーになっています。

```js
var appList = [
    { id: 'your-app-id-1', name: 'アプリ名1' },
    { id: 'your-app-id-2', name: 'アプリ名2' },
    { id: 'your-app-id-3', name: 'アプリ名3' },
    { id: 'your-app-id-4', name: 'アプリ名4' }
];
```

- `your-app-id-N` … 実際に配置したいKintoneアプリの**アプリID**（数値）に書き換えてください。
- `アプリ名N` … ポータルに表示する**ボタンの表示名**（絵文字を含めても構いません）に書き換えてください。
- 配置するアプリの数に応じて、行を自由に増減できます。

### `プロフィール閲覧制限/プロフィール閲覧制限カスタマイズ/config.js`

プロフィール閲覧を許可する組織・グループがプレースホルダーになっています。

```js
allowedOrgs: ['YOUR_ORG_CODE'],
allowedGroups: ['YOUR_GROUP_CODE'],
```

- `YOUR_ORG_CODE` … 閲覧を許可する**組織のコードまたは名前**に書き換えてください。
- `YOUR_GROUP_CODE` … 閲覧を許可する**グループのコードまたは名前**に書き換えてください。
- 複数指定する場合は配列にカンマ区切りで追加できます（例: `['YOUR_ORG_CODE_1', 'YOUR_ORG_CODE_2']`）。

`main.js`・`restriction.css` は固有情報を含まないため、無変更でそのまま利用できます。

### 書き換え不要なファイル

`ホームボタン/mobile-home-button.js`・`フォントサイズ/font-size-changer.js`・`モバイル版画像表示/` 配下は固有情報を含まないため、そのまま利用できます。

## 🚀 各機能の概要

- **ショートカットボタン**: ポータル上部に、よく使うアプリへのショートカットボタンを配置。カラーテーマ（🎨）・形状（🔲）を切り替え可能。
- **ホームボタン**: モバイル専用。画面下中央に、モバイルポータルへ戻る丸いボタン（FAB）を表示。
- **フォントサイズ変更**: 画面右下（メインポータルのみ）または右上（モバイルのその他画面）に常駐するウィジェットから、文字サイズを「小・中・大」の3段階で切り替え。PC/モバイル対応。
- **プロフィール閲覧制限**: 指定した組織・グループ以外のユーザーが、他ユーザーのプロフィール画面を閲覧できないよう制限。
- **モバイル版画像表示**: モバイル版Kintoneでの画像表示・拡大表示を改善するビューア。

各機能の詳細な仕様・設計思想は、コード内のコメントを参照してください。

## ⚙️ 導入方法

1. 上記のプレースホルダーを実際の値に書き換えます。
2. Kintoneのシステム管理から「JavaScript / CSS でカスタマイズ」を開き、対象ファイルを登録します（PC用／スマートフォン用の登録欄に注意してください）。
3. 設定を保存し、対象画面を再読み込みして動作を確認してください。
